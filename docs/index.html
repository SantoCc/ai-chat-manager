AI对话管理器

多个 AI 的对话，统一存进浏览器侧栏

手滑刷新、来回切换豆包 / 千问 / DeepSeek……对话不再散落各站。本地保存，可搜索、可导出，不上传到开发者服务器。支持 Edge（商店安装）与 Chrome（加载扩展文件夹）。

Edge：商店安装（推荐）

约 1 分钟 · 正式上架
  1. 打开 Microsoft Edge
  2. 进入扩展商店（或点下方按钮）
  3. 搜索 AI对话管理器 → 获取

Chrome：加载扩展文件夹

未上架 Chrome 商店 · 国内也难访问商店
  1. 打开仓库下载代码：GitHub · ai-chat-manager（Code → Download ZIP，解压）
  2. Chrome 打开 chrome://extensions/，开启右上角「开发者模式」
  3. 点「加载已解压的扩展程序」，选择解压后的项目根目录（内含 manifest.json）
  4. 打开豆包 / 千问 / DeepSeek 等对话页 → 点扩展图标打开侧栏 → 保存
Edge 商店安装 Chrome：去 GitHub 下载

小红书 / 微信等渠道：Edge 用户写搜「AI对话管理器」；Chrome 用户写「GitHub 搜 SantoCc/ai-chat-manager，开发者模式加载文件夹」。
